\# Lab 6 – Code and Branch Coverage Analysis



\## Project Overview

This project performs code coverage and branch coverage analysis on a Python-based Pizza Order application.



\## Features

\- Pizza pricing based on size and toppings.

\- Cheese burst additional charges.

\- Order discounts based on amount, day, and student status.

\- Delivery status based on delivery time and distance.



\## Requirements

\- Python 3.11+

\- pytest

\- coverage
